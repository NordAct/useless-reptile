## Example resource pack.
NOTE: THIS IS OUTDATED

Contains assets necessary for example data pack to work on client properly.

Additionally, allows to add glowing layer to either dragon or equipment texture. To add glowing layer to either dragon or equipment, add texture named after texture used by the model with `_glowing` suffix alongside said texture. I.e. if texture named `end.png`, to add glowing layer you have to add texture named `end_glowing.png` in the same folder where `end.png` is.
