- Порт на 1.21.11
- Кнопка полета вверх теперь по умолчанию привязана к левому Ctrl. Если вы обновляетесь с предыдущей версии игры, не забудьте ее привязать
- Поле "cull"C более не поддерживается для экипировки драконов
- Группы сущностей (spawn groups) теперь указываются как "категории мобов" ("mob categories") (или "категории" ("categories"))
- Geckolib был заменен новой библиотекой для анимаций (в данный момент она поставляется с модом, позже будет идти отдельно)
    - Это позволяет накладывать несколько анимаций на одну и ту же кость
    - Новая библиотека позволит добавить больше опций для кастомизации вариантов в будущем
    - Модели и анимации теперь используют полноценный формат из Bedrock'а
    - Светящиеся слои теперь могут быть анимированы (для примера можете глянуть вариант `jeb_` болотной виверны, который доступен через бирку)
- Все модели и анимации были обновлены вслед за сменой библиотеки анимаций
- Незеритовый и алмазные сеты брони для драконов были усилены
- Экипировка теперь может проигрывать различные анимации, которые зависят от анимаций, проигрываемых ее владельцем в данный момент
